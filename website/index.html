Nur noch FrankfurtFrankfurt only

Der Server-Lock sperrt über die Windows-Firewall ausgehendes UDP des Spiels zu allen anderen AWS-Standorten in Europa, über IPv4 und IPv6. Die Regel gilt nur für die Spiel-Exe. Browser, Discord und der Rest vom PC laufen normal weiter. The server lock uses Windows Firewall to block the game's outgoing UDP to every other AWS location in Europe, over IPv4 and IPv6. The rule only applies to the game's exe. Your browser, Discord and everything else keep working as usual.

Landet ein Match trotzdem woanders, etwa auf einem OVH-Server, merkt sich der Match-Server-Wächter die Adresse und sperrt sie nach dem Match. Mitten im Spiel wird nie etwas gesperrt. If a match still ends up somewhere else, on an OVH server for example, the match server watcher remembers the address and blocks it after the match. Nothing is ever blocked mid-game.

AWS ändert seine Adressbereiche regelmäßig. Neue Versionen bringen die aktuelle Liste mit und schreiben die Firewall-Regeln beim Start neu. AWS changes its address ranges regularly. New versions ship the current list and rewrite the firewall rules on start.

      Alles lässt sich zurücknehmenEverything can be undone

      Zurücksetzen fasst nur an, was die App selbst geändert hat. Vorher sichert sie die Originalwerte.       Was es nicht kannWhat it can't do

      Retrac Boost ändert nur, was auf deinem PC geht. Es leitet keinen Verkehr über andere Server um, so wie ExitLag mit seinem Relay-Netz. Ist der Weg zwischen deinem Provider und dem Spielserver schlecht, bleibt er schlecht. Retrac Boost only changes what can be changed on your PC. It doesn't route your traffic through other servers the way ExitLag does with its relay network. If the path between your provider and the game server is bad, it stays bad.

      • Kein Relay, kein VPNNo relay, no VPN
      • Kein Eingriff ins SpielNo hooks into the game
      • Keine Garantie auf weniger PingNo promise of lower ping

      FragenQuestions

      Verändert die App das Spiel?Does the app change the game?

      Sie öffnet nie ein Handle auf das Spiel. Die CPU-Priorität setzt Windows selbst beim Start. Das Alt+L-Fenster liegt nur darüber und ändert die Farbkurve des Bildschirms.It never opens a handle to the game. Windows itself sets the CPU priority on launch. The Alt+L window only sits on top and changes the screen's color curve.

      Die Potato-Grafik schreibt in die Einstellungsdateien des Spiels (Engine.ini, GameUserSettings.ini) und ins NVIDIA-Treiberprofil.Potato graphics writes to the game's settings files (Engine.ini, GameUserSettings.ini) and to the NVIDIA driver profile.

      Habe ich danach sicher weniger Ping?Will my ping definitely drop?

      Nein. Die App kann Schwankungen, Puffer und Energiesparen auf deinem PC angehen. Den Weg vom Provider zum Server ändert sie nicht. Was sich wirklich getan hat, siehst du unter dem Graphen bei Vorher und Jetzt.No. The app can deal with jitter, buffering and power saving on your PC. It can't change the path from your provider to the server. What actually changed shows up below the graph under Before and Now.

      Wie mache ich alles rückgängig?How do I undo everything?

      Über Zurücksetzen, für alles oder Zeile für Zeile. Die App stellt die gesicherten Originalwerte wieder her und löscht den angelegten Energiesparplan und ihre Firewall-Regeln.With Reset, for everything or row by row. The app restores the saved original values and removes the power plan and firewall rules it created.

      Brauche ich eine NVIDIA-Karte?Do I need an NVIDIA card?

      Nur für die Teile, die das NVIDIA-Profil setzen, also Teile vom FPS-Booster und den LOD-Bias der Potato-Grafik. Server-Lock, Ping-Werkzeuge und das Alt+L-Menü brauchen keine.Only for the parts that set the NVIDIA profile, meaning parts of the FPS booster and the potato graphics LOD bias. Server lock, ping tools and the Alt+L menu don't need one.

      Warum fragt Windows nach Adminrechten?Why does Windows ask for admin rights?

      Firewall-Regeln, Netzwerkkarte, Energiesparplan und DNS lassen sich unter Windows nur als Administrator ändern.Firewall rules, network card, power plan and DNS can only be changed as administrator on Windows.

      Ist das von Epic Games?Is this made by Epic Games?

      Nein. Retrac Boost ist ein eigenständiges Tool und hat nichts mit Epic Games oder dem Retrac-Team zu tun.No. Retrac Boost is an independent tool and isn't affiliated with Epic Games or the Retrac team.
