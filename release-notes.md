Ingame-Menü (Alt+L): Bildwerte nur noch im Spiel
- Gamma, Helligkeit, Kontrast und Farbton gelten jetzt nur, solange Fortnite (oder das unter Boost gewählte Spiel) im Vordergrund ist. In v1.0.4 wirkten sie auf dem ganzen PC.
- Beim Raustabben auf den Desktop oder in ein anderes Programm sind sofort die normalen Werte da. Beim Zurücktabben kommen deine Werte wieder.
- Bei mehreren Bildschirmen wird nur der Bildschirm verändert, auf dem das Spiel läuft.
- Im Spiel selbst wird weiterhin nichts verändert.

In-game menu (Alt+L): picture values only in the game
- Gamma, brightness, contrast and color tone now only apply while the game is in front, and only on the screen it runs on. Tab out and your PC looks normal right away.

Wichtig für v1.0.1 und v1.0.2
- In diesen Versionen funktioniert der Update-Knopf noch nicht. Einmal RetracBoost-Setup.exe von dieser Seite installieren, danach klappt er.
